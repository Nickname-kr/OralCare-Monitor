# OralCare Monitor · Phase 2 Camera Prototype

구강점막 병소 반복 촬영 앱의 **2차 카메라 연동 시제품**입니다.

## 이번 수정사항

- 구강 해부학 그림을 새 SVG로 전면 수정
- 환자에게 익숙한 명칭 사용: 입술, 잇몸, 입천장, 볼, 혀, 입바닥, 어금니 뒤, 목 안쪽
- 큰 부위 선택 후 세부 위치 선택
- 혀 선택 시 윗면 / 아랫면 / 왼쪽 옆면 / 오른쪽 옆면 제공
- `연구번호` 표기를 `환자번호`로 변경
- 스마트폰 실시간 카메라 연결
- 후면/전면 카메라 전환
- 기준 사진 파일 선택 및 반투명 오버레이
- 오버레이 투명도 조절
- 실제 촬영 및 결과 화면 표시
- 실시간 카메라를 사용할 수 없을 때 휴대폰 기본 카메라 입력 제공
- 해상도와 평균 밝기의 기초적인 확인

## 중요한 실행 조건

실시간 카메라는 보안 연결에서만 작동합니다.

- GitHub Pages의 `https://...` 주소: 사용 가능
- `localhost`: 사용 가능
- 컴퓨터에서 `index.html`을 단순 더블클릭한 `file://` 주소: 실시간 카메라가 제한될 수 있음

더블클릭 환경에서는 카메라 화면의 **휴대폰 기본 카메라 사용** 기능으로 사진 파일을 선택할 수 있습니다.

## GitHub Pages에 업데이트하기

기존 저장소의 다음 파일을 이번 버전의 파일로 교체합니다.

- `index.html`
- `style.css`
- `app.js`
- `README.md`

파일을 `main` 브랜치의 저장소 최상단에 커밋하면 GitHub Pages가 자동으로 다시 배포됩니다.

1. 시제품 시작하기
2. 촬영하기
3. 큰 부위 선택
4. 세부 위치 선택
5. 촬영 가이드 보기
6. 촬영 화면 보기
7. 카메라 권한 허용
8. 기준 사진 선택

10. 촬영 버튼 누르기
11. 촬영 결과 확인

## 현재 데이터 처리 방식

- 기준 사진과 촬영 사진은 현재 열린 페이지의 메모리에만 유지됩니다.
- 서버나 GitHub 저장소로 업로드하지 않습니다.
- 페이지를 새로고침하거나 닫으면 초기화됩니다.
- 3차에서 IndexedDB를 이용한 기기 내부 저장과 타임라인 연결을 구현할 예정입니다.

- 실제 PDF 생성

- AI 병소 인식 및 변화 판정
