# OralCare Monitor · Phase 1 UX Prototype

구강점막 병소 환자의 반복 촬영 및 기록 흐름을 검토하기 위한 **클릭형 모바일 웹앱 시제품**입니다.

## 이번 버전에서 가능한 것

- 홈 대시보드
- 촬영 부위 선택
- 촬영 가이드
- 기준 사진 반투명 오버레이 목업
- 오버레이 투명도 조절
- 촬영 결과 및 품질 체크 화면
- 증상 기록
- 기록 타임라인
- 사진 비교 슬라이더
- 리포트 미리보기
- 전체 화면 간 버튼 이동

## 아직 구현하지 않은 것

- 실제 스마트폰 카메라 접근
- 실제 사진 저장
- 오프라인 저장
- 알림
- PDF 파일 생성
- 로그인 및 서버
- 병소 자동 분석
- 의료진용 시스템 연결

## 로컬에서 실행하기

1. 폴더 안의 `index.html`을 더블클릭합니다.
2. 또는 VS Code의 **Live Server** 확장 기능으로 실행합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`, `style.css`, `app.js`를 저장소 최상단에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. Source에서 **Deploy from a branch**를 선택합니다.
5. Branch를 `main`, 폴더를 `/root`로 선택하고 저장합니다.
6. 잠시 뒤 표시되는 GitHub Pages 주소를 스마트폰에서 엽니다.
