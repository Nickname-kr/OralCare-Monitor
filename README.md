# OralCare Monitor · Phase 3

구강점막 병소 환자가 동일 부위를 반복 촬영하고, 사진·증상·메모를 **현재 기기의 브라우저 내부 저장소(IndexedDB)** 에 보관하는 모바일 웹앱 시제품입니다.

## 이번 3차 버전의 핵심 기능

- 환자번호, 표시 이름, 기본 촬영 간격 저장
- 환자가 이해하기 쉬운 큰 부위 선택
  - 입술
  - 입천장
  - 볼
  - 잇몸
  - 혀
  - 입바닥
  - 어금니 뒤
  - 목 안쪽
- 큰 부위 선택 후 세부 위치 선택
- 혀 선택 후 윗면·아랫면·왼쪽 옆면·오른쪽 옆면 선택
- 세부 위치별 일관된 구강 그림 제공
- 실제 스마트폰 카메라 연동
- 전면 카메라 미리보기는 거울 화면으로 표시
- 전면 카메라 촬영 결과는 실제 해부학적 좌우 방향으로 저장
- 가져온 사진의 방향이 잘못된 경우 수동 좌우 반전
- 첫 사진을 해당 세부 위치의 기준 사진으로 자동 지정
- 이후 같은 위치 촬영 시 기준 사진 반투명 오버레이
- 오버레이 투명도 조절
- `특별한 증상 없음` 항목 추가
- 증상 없음과 다른 증상의 동시 선택 방지
- 사진·증상·메모·촬영 위치·촬영일을 IndexedDB에 저장
- 페이지 새로고침 또는 재접속 후 기록 복원
- 실제 기록 기반 홈 화면과 타임라인
- 기록 상세 조회, 증상·메모 수정, 기록 삭제
- 기준 사진 변경
- 같은 세부 위치 사진의 겹쳐 보기·나란히 보기 비교
- 기기 내부 저장량 안내
- 모든 로컬 데이터 삭제

## GitHub Pages에 적용하는 방법

기존 저장소 최상단의 다음 파일을 3차 버전 파일로 교체합니다.

```text
index.html
style.css
app.js
README.md
```

업로드 후 `Commit changes`를 누릅니다. 기존에 GitHub Pages가 `main / (root)`로 설정되어 있다면 새 커밋 후 자동으로 다시 배포됩니다.

이전 캐시가 계속 보이면 주소 뒤에 임시 버전 값을 붙여 접속합니다.

```text
https://사용자명.github.io/저장소명/?v=3
```

## 권장 테스트 순서

1. 환자번호와 촬영 간격 등록
2. 큰 부위 선택
3. 세부 위치 선택
4. 첫 사진 촬영
5. `특별한 증상 없음` 선택
6. 기록 저장
7. 페이지 새로고침
8. 홈과 타임라인에서 기록 복원 확인
9. 같은 세부 위치를 다시 촬영
10. 기준 사진 오버레이 확인
11. 두 사진 비교

## 카메라 좌우 방향 처리

- **전면 카메라 미리보기:** 사용자가 위치를 맞추기 쉽도록 거울처럼 표시
- **저장 결과:** CSS 거울 효과가 적용되지 않은 원본 프레임을 저장하여 실제 좌우 방향으로 표시
- **후면 카메라:** 미리보기와 저장 결과 모두 실제 좌우 방향
- **기본 카메라 또는 앨범 사진:** 방향이 잘못된 경우 결과 화면의 `좌우 반전` 버튼 사용

## 저장 방식과 주의점

사진과 증상 기록은 GitHub에 올라가지 않고 해당 기기의 브라우저 안에 저장됩니다.

다음 상황에서는 기록이 사라질 수 있습니다.

- 브라우저 데이터 삭제
- 시크릿 모드 사용
- 다른 브라우저 또는 다른 기기에서 접속
- 기기 초기화
- 저장 공간 정리 기능 실행

실제 환자 연구 적용 전에는 다음 4차 단계에서 백업·복원과 PDF 생성 기능을 추가하는 것이 필요합니다.

## 4차 예정 기능

- 전체 기록 백업 파일 생성
- 백업 파일 복원
- 실제 PDF 리포트 생성
- 기간과 사진 선택
- 의료진용 자료 내보내기
